# Slice 07 Settings shots

Rendered with `apps/macos/tests/settings-view-shots.mjs` (production `SettingsView`, no service).
`before-light.png` is the read-only list this slice replaced. The others are the accepted
click-to-record fields: always-on and while-recording groups, a field recording keys, a key
refused by macOS (dark) and a duplicate inside Yap. Three unprimed critiques shaped them: rows
are one line with label and field aligned, warnings only for real conflicts, the lifetime is
stated once per group instead of on every row.
