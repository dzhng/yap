# Scrawl reference frames

Stills from Kit Langton's Scrawl demo (<https://x.com/kitlangton/status/2111955962781384846>,
source <https://github.com/kitlangton/scrawl>, MIT). They are the behaviour and look Yap's
"show your agent" loop was modelled on, not a target to match pixel for pixel.

- `ink-and-pin-live.jpg`: red ink drawn over a live window while recording.
- `control-bar-and-bundle.jpg`: Scrawl's recording island (timer, Undo, Cancel, Finish) above
  an annotated keyframe.
- `pasted-handoff.jpg`: the handoff pasted into an agent session.
- `contact-sheet.jpg`: six frames from the demo, for context.

Scrawl's handoff pastes a contact-sheet image and a transcript with timecodes; Yap's pastes a
text prompt only (decision D2/D3′ in the [spec](../../README.md)). Judge ink colour, fade and pin
badges against these frames in [slice 05](../../slices/05-ink-overlay.md) with
compare-screenshots, as a reference, not as an approved design.
