# Ink

[Ink](Ink.swift) is how a person's marks look: the red strokes, the numbered pin badges and the
way each fades. The app draws them live over the displays and
[frames](../YapFrames/README.md) draw them over review renders of the recording, both through
this one owner, so an agent reading a frame sees what the person saw.

When a mark is on screen is not decided here. The capture writer stamps each mark with the
window it was shown for and journals it; every drawer reads that window.
